# JR-100公開ゲーム候補の評価

評価日：2026-09-11。対象は標準RAM 16KBのJR-100。

原案は依頼者から提供された「レトロPCで動くゲームアイディア100選」の全文。前半の100案に続く会話で「ゲームのアイディアはモダンな方が良い」と方針が変わっているため、後半を開発の中心にする。原文の転載ではなく、JR-100向けの技術評価と開発上の判断を記す。

**すべて設計時点の評価であり、実装済み・動作確認済みという意味ではない。** 「後続」は優先順位の判断であって、ハードウェア上の不可能を意味しない。既存作品を参照する原案は仕組みの着想として扱い、公開名・画像・曲・文章・ステージは独自に作る。
