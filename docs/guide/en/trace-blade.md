Plan one continuous sword path through 30 rooms. On each 12×9 board, pass through every target and finish at the diamond-shaped exit, then execute your route. The blade follows your plan and strikes each target in sequence.

## Controls

| Action | Keyboard | One-button pad |
| --- | --- | --- |
| Extend the path one cell | W/A/S/D | Up/down/left/right |
| Menu / confirm | RETURN | Button |
| Select menu entry | W/S | Up/down |
| Undo one step | SPACE | UNDO in the menu |
| Execute | F | CUT in the menu |
| Return to BASIC | CTRL+C | Use the keyboard |

You cannot cross a wall or revisit a cell. Take as long as you like to plan; undo one step at a time, all the way to the start. A route can execute only if it includes all targets and ends at the exit. RESET clears the current room's route; TITLE returns to the title; BACK resumes planning.

TARGET is the total target count, MARKED is the number included in your route, PATH is its length, and COMBO counts strikes during execution. Targets included in the route gain corner marks. Execution runs automatically; press the button after clearing the room to continue.
