# 未個別改修作品の再点検

共通演出を加えたことと、個々の遊びを十分に磨いたことを区別する。既に個別改修した20作品は今回の変更対象から外し、残る31作品を再点検する。

## 今回も守る基準

1. タイトルと本編の絵柄を揃え、セミグラフィックス、PCG、陰影で操作対象を見分けられる画面にする。
2. 移動、反転、発射、着弾、収穫には途中の位置・形を入れる。共有PCGを書き換えて別の個体まで変化させない。
3. 動作にSEを合わせ、被害の原因と短い停止、成功・失敗のジングルを残す。
4. 常設の説明はタイトル・ヘルプへまとめ、本編には選択対象、予告、資源、結果を表示する。
5. 面数だけを増やさず、配置・資源・相手の応答・任意の報酬によって選択を変える。
6. 3枚以上の紹介画像の後に、最初の目標達成までを省略しない動画を置く。
7. 標準16KB・PCG32文字でビルド、エミュレーターの入力と実画面・PCM、公開URLをそれぞれ確認する。実機未確認を明記する。

## 範囲

25作品のネイティブルールを持つ小規模ゲームを個別に改修する。CHRONO BREACH、SIGIL DECK、ABYSS SIGNAL、TRACE BLADE、LOOP TEN、RELIC DIVEは、既存の多段階の攻略・資源管理と個別の演出を点検し、必要性のないルール変更は行わない。

## 既存6作品の点検

CHRONO BREACHの20面、SIGIL DECKのカード構築と連戦、ABYSS SIGNALの酸素・電池・ソナー、TRACE BLADEの30部屋の一筆経路、LOOP TENの持ち越す封印と10秒制限、RELIC DIVEの探索・資源・戦闘を再点検しました。いずれも既存の攻略と個別演出を維持し、ビルドと入力リプレイを再実行しています。


## 検証

- 改修した25作品・計221ステージを通常の入力でクリア。各作品の16KB配置、32文字のPCG、スタックとコード領域の保持を確認しました。コード・定数は7,042〜10,165バイトです。
- 各作品160回のキーボード・パッド混合入力、やり直し、画面範囲を検査。競りは256種の開始値×3市場、カードは256通りの52枚の山札、受け流し・装甲・過熱・網・作物・着陸・測定の成功と失敗を追加検証しました。
- 所有BASIC ROMから起動したエミュレーターで全25作品を通しプレイし、画面を確認しました。反転・移動・被弾の中間表示、局所的なPCG書換え、開始と結果の入力抑止、SEとジングルも確認しています。
- 25作品の開始・進行・クリアの3画像と動画を更新しました。動画は30〜86秒。最初の目標達成までを省略せず、通常速度で収録しています。音声はエミュレーターのPCMです。
- 公開動画の全51本をデコードし、153画像、音声、クリアイベント、PRGとのSHA-256一致を検査しました。
- 実機での動作・音声は未確認です。
