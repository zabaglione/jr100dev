# JR-100公開ゲーム集の構成

標準RAM 16KB向けに、最初の6作品、新作44作品、RELIC DIVEを合わせた51作品を収録します。作品・ジャンル・概要の正本は `games/library.json`、ビルド対象は `games/collection.json` です。[ゲーム一覧](../games/README.md)から作品ごとの遊び方とソースを参照できます。

## 対象と実装

JR-100のMB8861H、RAM `$0000–$3FFF`、PCG32文字、32×24文字画面、単音を対象とします。JR-800用の画素描画や増設RAMは前提にしません。サンプルは作品数に含めません。

最初の6作品とRELIC DIVEはアセンブリ、新作44作品は作品ごとの `rules.py` をビルド時にMB8861H機械語へ変換します。新作はそれぞれの仕組みを短い対戦、課題集、固定画面のアクションとして実装しています。具体的なステージ数・目標・制限は各作品の説明書に記載しています。

ゲーム本体は `$0300` から配置し、画面バッファ・作業状態・BASIC復帰用保存領域・512 bytesのスタックを含めて16KB内に収めます。6809命令は使用しません。

## 操作と画面

4方向はWASD（W上・A左・S下・D右）、8方向のNIGHT SWARMとRELIC DIVEはQWE／AD／ZXCを使います。CHRONO BREACHとABYSS SIGNALの待機はX、RELIC DIVEの待機はSです。決定はRETURN、主な操作は1ボタンパッドでも入力できます。説明表示・任意の再開始・BASICへの復帰に必要なキーは作品別に案内します。

各タイトルには固有の図案とロゴ配置を用意します。ゲーム中は地図、手札、回路、炉、軌道、走路、着陸計器など、遊びに合わせた盤面と表示を使います。画面の文字は英数字で、説明書とWikiは日本語です。

全51作品に効果音があります。RELIC DIVEは開始・被弾・攻撃と成功・失敗のジングルを使います。新作44作品のタイトル曲は32小節の単音曲で、ゲーム中は効果音を使います。最初の6作品は各作品の音楽構成を維持します。BGMと効果音の同時発音は行わず、重要な効果音を優先します。

## 検証と公開

- 全51作品のRAM配置、PCG数、スタック、命令のビルド検査。
- キーボードとパッドによる入力、全ステージまたは勝利条件までのリプレイ、ルールとの照合。
- 新作44作品では各160イベントの入力・時間経過・失敗・やり直しと描画範囲の検査。
- 所有するBASIC ROMからの起動と、タイトル・ゲーム中の実フレーム取得。
- Web配布物のPRG一覧とSHA-256、WASM版の標準16KB起動・開始入力・PCMの確認。

エミュレーターでの検証を実機動作の証明とは扱いません。実機の操作・映像・音声は未確認です。

Wikiは6ジャンル、タイトル順索引、共通操作、51作品の個別ページで構成します。各ページから、保存済みBASIC ROMを使うWebエミュレーターへゲームID付きで起動できます。ROMは配布物に含めません。公開コミットは確認済みのGitHub noreplyメールを使います。

## アイディアの出典

依頼者から貼り付けられた「レトロPCで動くゲームアイディア100選」を出発点にしています。JR-100向けの候補評価は[候補一覧](public-games-candidates.md)に残しています。原案にあるVRAM `$0100–$03FF` は誤記で、JR-100の表示RAMは `$C100–$C3FF` です。
