# JR-100サンプルコード

このディレクトリには、JR-100固有の開発ルールを実際のコードで確認できるサンプルがあります。先に`rules/README.md`を読み、次の順で進めると機能を段階的に追えます。

| 順序 | サンプル | 主題 |
| --- | --- | --- |
| 1 | `hello` | `$0300`からの開始とVRAM直接書き込み |
| 2 | `counter` | 標準マクロと`FOR` |
| 3 | `io_demo` | VRAM、キー入力、簡易ビープ |
| 4 | `key_display` | VIAによるキーマトリクス読み取り |
| 5 | `multi` | 複数ソースのアセンブルとリンク |
| 6 | `pcg_clock` | PCG、PB5、サイクル計測 |
| 7 | `pcg_animation` | 4スロットで動かす2×2・4方向・2パターンPCGアニメーション |
| 8 | `maze` | 迷路生成、入力、ワーク領域、スクロール |

## ビルド

リポジトリルートから個別にビルドします。

```sh
make -C samples/hello
make -C samples/pcg_clock
```

全サンプルをまとめてビルドする場合は次を実行します。

```sh
make samples
```

成果物は各サンプルの`build/`へ生成されます。実行方法と期待結果は、それぞれのREADMEを参照してください。
