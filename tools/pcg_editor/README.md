# JR-100 PCG / Animation / CRT Workbench

JR-100 のPCG、アニメーション、32×24文字画面を一つのプロジェクトで編集する、依存ライブラリ不要のWebアプリです。PCG Editorはユーザー定義文字32スロット（`$C000-$C0FF`）を扱い、CRT Editorは画面VRAM 768バイト（`$C100-$C3FF`）を扱います。

## 起動

リポジトリルートから次を実行します。

```sh
cd tools/pcg_editor
npm run serve
```

ブラウザーで `http://localhost:8000` を開きます。外部パッケージのインストールは不要です。

## 主な操作

### PCG Editor

- 左ドラッグ: ドットを描画
- 右ドラッグ: ドットを消去
- `Shift`を押しながらLineを描画: 水平・垂直・45度へ制約
- `Shift`を押しながらRectangleを描画: 正方形へ制約
- `Esc`: 描画中のストロークを取り消す
- `1x1`、`2x2`、`3x3`: 連続スロットを一枚のキャンバスとして編集
- Saved group: 大型キャラクターの名前、寸法、先頭スロットをプロジェクトへ保存
- Pencil / Eraser / Line / Rectangle / Fill: 描画ツール切替
- Grid: 1ドット単位のグリッド表示を切り替え
- Shift / Flip / Invert / Clear: 編集中キャンバス全体の変形
- Undo / Redo: ストロークまたは一括操作単位で復元
- PCG Library: 160個の組み込みプリセットを検索、カテゴリ、サイズ、種別、Favorites、Recentで絞り込み
- PCG Libraryは8×8部品、16×16複合文字、複数部品セットを実寸プレビューで確認してから適用
- 適用先の開始スロットを指定し、使用済みスロット、保存済み複合文字、アニメーションに重なる場合は確認して置換
- ASM Output: PCG 256バイト、画面VRAM 768バイト、または両方を `.byte` 形式でコピーまたはダウンロード
- Save JSON / Import: 編集プロジェクトを保存・復元

### CRT Editor

- PCG Editor / CRT Editor / Animation: ヘッダーから編集画面を切り替え
- Character Palette: VRAMコード`$00-$FF`の全256値、または文字種別の絞り込みから選択
- 左ドラッグ: 選択中のVRAMコードを画面へ配置
- 右ドラッグ: 空白コードを配置
- 矢印キー: 画面カーソルを移動
- `Space`または`Enter`: カーソル位置へ選択コードを配置
- Text / Place text: ASCII文字列をJR-100のROM文字コードへ変換して配置
- Fill / Clear: 画面を選択コードまたは空白で埋める
- Show all PCG: `$80-$9F`を画面へ並べ、全32 PCGスロットを同時確認
- Grid: 文字セル境界の表示切替
- PCG Coverage: 現在の画面に配置されているPCGスロットを一覧表示
- VRAM-backed glyph: `$A0-$FF`選択時に、定義元となる画面VRAM 8バイトを8×8ドットとして直接編集。該当する画面セルも赤枠で表示

赤枠は常時表示されません。`$A0-$FF`を選択すると現れる「VRAM定義元を表示」をオンにした場合だけ、選択字形の定義元である8個の画面VRAMセルを表示します。画面下部の凡例にも同じ意味を表示します。

### Animation

1. 「新規クリップ」で常駐先スロット、複合文字の列数・行数、フレーム時間を設定します。
2. 「PCG編集へ」で同じスロット範囲を編集し、アニメーションへ戻ります。
3. `RIGHT_0`などのフレーム名を付け、「常駐スロットを取込」で現在の字形を保存します。
4. 各フレームを選び「PCG編集へ」と「選択フレームを更新」を繰り返します。
5. 再生で切替を確認し、ASM出力の「アニメーション」からフレームデータとポインタ表を取得します。

フレームポインタ表はタイムライン順です。4方向×2パターンのサンプルでは、`LEFT_0`、`LEFT_1`、`RIGHT_0`、`RIGHT_1`、`UP_0`、`UP_1`、`DOWN_0`、`DOWN_1`の順に並べ、ASM出力ラベルを`PLAYER`にします。

2×2の場合、画面が使うPCGコードは常に4個です。8フレームを登録しても常駐PCGは4スロットのままで、プログラム側は選択フレームの32バイトを常駐先へコピーします。実装例は[`samples/pcg_animation`](../../samples/pcg_animation/)を参照してください。

### Experimental: Image Mosaic

CRT Editorの「画像モザイク」からPNG、JPEG、WebP、GIF画像を読み込み、32×24文字のJR-100画面へ近似変換できます。入力画像を256×192ドットへ配置した後、8×8ドット単位で候補字形との二乗誤差を計算し、最も近い文字コードを選びます。

- 配置: 画面を埋める切り抜き、画像全体を表示、引き伸ばし
- 文字候補: 現在のCMODEで利用可能な文字、ROM文字、記号・セミグラフィック、PCG
- 階調変換: 濃淡誤差、二値化、4×4組織的ディザ
- 調整: コントラスト、しきい値、明暗反転、RGB色差を使った輪郭強調
- PCG自動生成: 既存文字との誤差を最も減らせる8×8パターンを最大32個生成し、ROM文字と組み合わせて再変換

この機能は実験段階です。写真を正確に再現するものではなく、使用する文字ROMやPCG、画像の構図、コントラストによって結果が大きく変わります。PCGモードの`$A0-$FF`は画面VRAM自身を字形データにするため、変換候補から除外しています。画像の読込後はパラメータ変更に合わせてプレビューが自動更新され、この段階ではプロジェクトを変更しません。「画面編集へ適用」を実行すると768バイトの画面データがUndo履歴とJSON保存の対象になり、PCG自動生成を有効にした場合は生成数分のPCGスロットを`$80`から順に同じUndo単位で置き換えます。置換範囲外のPCGは保持し、置換範囲と重なる複合文字・アニメーション設定は解除します。

## 表示言語

画面右上の言語選択から日本語と英語を切り替えられます。初回表示は日本語です。選択した言語はブラウザーへ保存され、次回起動時にも使用されます。翻訳データは`locales/ja.js`と`locales/en.js`へ分離しています。

## 表示モードと文字コード

VRAMのbit 7は各セルの文字属性として扱います。bit 7が0の`$00-$7F`は、どちらのCMODEでもROMの全128文字を表示します。

- CMODE PCG: `$80-$9F`は通常の32 PCG文字、`$A0-$FF`は画面VRAMと定義領域が重なる追加96 PCG文字
- CMODE inverse: `$80-$FF`は対応するROM文字の反転表示

ROM文字、記号、セミグラフィックはPCGと同一画面で使用できます。PCGと反転文字は同じCMODEでは使用できません。

内蔵フォントは、ROMファイルを同梱しないための近似表示です。実機と同じ全128 ROM字形で編集する場合は、JR-100 ROMのPROGファイルをCRT EditorのImport ROM / PROGで読み込んでください。エミュレーターのROMローダーが使うversion 1形式と、複数PBINセクションを持てるversion 2形式に対応し、`$E000-$E3FF`を含むバイナリ領域から1024バイトを切り出します。読み込んだ字形、画面、PCGはJSONプロジェクトへまとめて保存されます。

プロジェクトはブラウザーの `localStorage` にも自動保存されます。

### PCG Library

PCG Editor右側の「PCG Library」から開きます。ライブラリーは、サイドビュー・トップビュー向け地形、記号、文房具、乗り物、生物・キャラクターを収録します。個別の8×8・16×16定義に加えて、道路、川、航空機などのセットも選べます。

1. 検索、カテゴリ、サイズ、種別で候補を絞り込みます。Favoritesはブラウザーに保存され、Recentには直近12件の適用履歴が表示されます。
2. カードを選び、右側のプレビューと必要スロット数を確認します。カードを選ぶだけではプロジェクトは変更されません。
3. 開始スロットを指定して「Apply to PCG」を実行します。対象が空なら直ちに適用し、既存データに重なる場合は削除対象を確認してから置換します。
4. 16×16定義とセットは保存済み複合文字として開かれるため、続けてドット単位で編集できます。適用全体は一回のUndoで戻せます。

ライブラリーの識別子、アセット名、ASM出力へ入る名前はASCII英語です。巨大戦艦のように32スロットを超えやすい大型素材は収録しません。

キャンバスへフォーカスした状態では、矢印キーでカーソル移動、`Space`または`Enter`で描画、`[`と`]`で編集スロット移動、`1`から`3`で複合サイズを変更できます。ワークスペース全体のシフトは`Alt+矢印キー`です。`X`でPencilとEraserを切り替えます。

デスクトップ表示は1920×1080を基準に、ヘッダー、32スロット、キャンバス、プレビュー、バイト表示が縦スクロールなしで収まる密度に調整しています。狭い画面では2列または1列へ切り替わります。
