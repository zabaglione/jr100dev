# JR-100ハードウェアルール

## CPUとクロック

- CPUはMB8861Hです。命令体系は6800/6802系として扱います。
- 開発上の基準クロックは`894000 Hz`です。実機資料に基づく精密な音程計算などでは`894886.25 Hz`を使う場合があるため、用途と前提を明記します。
- タイミング待ちをCPUループで作る場合は、命令ごとのサイクル数と分岐成立時の差を数えます。

## 主なメモリとI/O

| 範囲またはアドレス | 用途 |
| --- | --- |
| `$0300` | サンプルの標準エントリポイント |
| `$C000-$C0FF` | PCGデータ、32文字×8バイト |
| `$C100-$C3FF` | 32列×24行のVRAM |
| `$C800-$C80F` | VIA 6522レジスタ |

コードとデータを配置するときは、BASICワーク領域、スタック、VRAM、I/O領域との衝突を避けます。リンクマップで最終アドレスを必ず確認してください。

## VRAM

- VRAM先頭は`$C100`、終端の次は`$C400`です。
- 画面は32列×24行で、1文字が1バイトに対応します。
- JR-100の表示コードはASCIIと完全には一致しません。既存の変換処理またはサンプルで、空白や英数字の扱いを確認してください。

## PCG

- PCG領域は`$C000-$C0FF`です。
- 1文字は8行、各行1バイトの8×8ドットで、32文字分を保持します。
- ユーザー定義文字は文字コード`$80-$9F`で表示します。
- PCG文字面を使うときはVIAのPB5を出力かつHighにします。他のPBビットを壊さないよう、DDRBとORBは読み出した値にPB5だけを加えます。

## VIAとサウンド

- VIAのベースアドレスは`$C800`です。
- JR-100の音声出力はPB7の矩形波をスピーカーへ送る単音出力です。音量制御や同時発音はありません。
- タイマー1をフリーランニングのPB7出力、タイマー2をPB6のパルス計数として利用できます。
- ACRの設定、IFRのクリア、タイマー下位・上位バイトの書き込み順は、目的とする動作に合わせて明示します。
- 既存のVIA設定を変更する処理は、キーボードやPCG選択など他の機能へ影響しないか確認します。
